## Folder rule for contributors

Put everything for your pattern inside its own folder, so we never edit each other's files:

```
<Pattern_Name>_Pattern/
├── README.md        how to build and run
├── src/             source code
├── docs/            PDF documentation, UML diagrams, code review report
└── ...
```
